# 🧠 Application 09 - Named Entity Recognition

## 🎯 Aim

To identify important named entities from text using JavaScript.

## 📖 Description

Named Entity Recognition (NER) is an important Natural Language Processing technique.

It identifies specific information from text such as:

- 👤 People
- 📍 Places
- 🏢 Organizations
- 📧 Email addresses
- 📅 Dates

## ✨ Features

- Simple and attractive interface
- People name detection
- Place detection
- Organization detection
- Email detection
- Date detection
- Clear button
- Mobile-friendly design
- Real-time result display

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Regular Expressions
- NLP concepts

## ⚙️ How It Works

1. User enters a paragraph.
2. JavaScript analyzes the text.
3. Regular expressions identify specific patterns.
4. Known place names are detected.
5. Organizations and person names are identified.
6. The detected entities are displayed in separate sections.

## 🧪 Example Input

Srinath studies at Prathyusha Engineering College in Chennai.

His email is student@gmail.com.

The exam is on 25/09/2026.

## 📊 Example Output

### People
Sriram

### Places
Chennai

### Organizations
Prathyusha Engineering College

### Emails
student@gmail.com

### Dates
25/09/2026
